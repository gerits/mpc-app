# Bundled SoundFonts & Attributions

MiniStation includes open-source, permissively-licensed SoundFont (.sf2) soundbanks for instant plug-and-play performance:

### 1. `General_GM.sf2` (TimGM6mb)
- **License**: GNU General Public License v2 (GPLv2) / Open SoundFont Collection
- **Origin**: Tim Brechbill / MuseScore project
- **Instruments Included**:
  - Acoustic Grand Piano (Bank 0, Patch 0)
  - Vintage Electric Piano / Rhodes (Bank 0, Patch 4)
  - DX-style FM Electric Piano (Bank 0, Patch 5)
  - Acoustic & Electric Bass (Bank 0, Patches 32–34)
  - Synth Bass 1 & 2 (Bank 0, Patches 38–39)
  - Analog Synth Leads (Square, Sawtooth) (Bank 0, Patches 80–81)
  - Lush Warm Synth Pads (Bank 0, Patches 88–91)
  - Full General MIDI Standard Percussion Kit (Bank 128, Patch 0)
  - Roland TR-808 Electronic Drum Kit (Bank 128, Patch 25)

### 2. `Acoustic_Grand.sf2`
- **License**: Public Domain / Permissive Open Distribution
- **Origin**: Curated compact GM piano & keyboard soundbank
- **Instruments Included**:
  - Concert Grand Piano (Bank 0, Patch 0)
  - Bright Acoustic Piano (Bank 0, Patch 1)
  - Honky-Tonk Piano (Bank 0, Patch 3)
  - Vintage Rhodes E.Piano (Bank 0, Patch 4)
  - 60's Combo Organ & Electric Pianos (Bank 0, Patches 4–5)

### 3. `909_drums.sf2`
- **License**: Creative Commons Attribution 3.0 (CC BY 3.0)
- **Origin**: Roland TR-909 sampling project via Musical Artifacts / Polyphone community
- **Instruments Included**:
  - Roland TR-909 Sustained Drum Kit (Bank 0, Patch 0)
  - Roland TR-909 Staccato Drum Kit (Bank 0, Patch 1)
